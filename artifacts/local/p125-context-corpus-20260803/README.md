# p125 prepared-context corpus evidence

`result.json` is the compact, independently audited record for the level-193
control and level-277 crossover A/B. `SHA256SUMS` is generated from the exact
committed JSON bytes. Raw benchmark outputs are intentionally omitted from the
repository; their per-run projection hashes, timing vectors, binary identities,
and source identities are retained in the compact record.

See [`docs/quotient_context_corpus_ab.md`](../../../docs/quotient_context_corpus_ab.md)
for methodology, interpretation, reproduction commands, and limitations.
